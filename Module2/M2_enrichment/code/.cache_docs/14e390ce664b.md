# Troubleshooting: типовые сбои агента

## Таймауты инструментов

Симптом: в JSONL-логе `tool_error` с кодом `timeout`, затем повтор.
Действия: проверить `tool_timeout` в конфигурации цикла; для внешних
сервисов поднять лимит до 15–30 секунд; убедиться, что ошибка помечена
`retryable`, иначе повтора не будет.

## Ошибки парсинга решений

Симптом: `parse_error`, модель отвечает прозой вместо JSON.
Действия: проверить системный промпт — есть ли протокол и список
инструментов; посмотреть сырой ответ (`raw` в событии лога); при
markdown-фенсах убедиться, что парсер их снимает.

## Пустой diff и «изменений нет»

Инструмент `git_diff` вернул «изменений нет» — это валидный результат,
а не сбой. Не повторять вызов и не считать задачу проваленной: сообщить
пользователю, что рабочее дерево чистое.
