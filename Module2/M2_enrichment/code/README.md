# Лабораторная 2.7 — Обогащение: внешние источники знаний

**Цель:** подключить внешний источник знаний (документация проекта) к агенту:
кэш с TTL → глоссарий предметной области → индекс из 2.4 → контекст в бюджет.

## Структура

```text
lab_2_7_enrichment/
├── corpus/            # «внешняя» документация: deploy.md, api.md, troubleshooting.md
├── data/glossary.json # термины + синонимы + определения (онтология-лайт)
├── docs_cache.py      # DocCache: файлы/тексты/URL, sha-дедупликация, TTL
├── glossary.py        # Glossary: lookup по алиасам, expand в промпт
├── enrich.py          # enrich(): глоссарий + retrieval + pack_context
└── tests/test_enrich.py
```

## Шаги практики

1. **Демо (офлайн):**

   ```powershell
   cd code\lab_2_7_enrichment
   python enrich.py --question "как откатить неудачный деплой"
   ```

   В выводе: сработавшие термины (`откат`, `деплой`), источники
   (`deploy.md`), предупреждение о просроченном кэше (если есть),
   собранный блок контекста и `--ask` для передачи в LLM.

2. **Тесты:**

   ```powershell
   python -m pytest -q
   ```

3. **Внешний URL без сети не работает — и это фича:**

   ```powershell
   python -c "from docs_cache import DocCache; DocCache('.c').add_url('https://example.com/x')"
   # CacheError: офлайн ... — сеть только через fetcher с таймаутом/ретраями (см. 2.5)
   ```

4. **(Самостоятельно)** Добавьте 4-й документ и термин глоссария, проверьте,
   что `enrich` находит новый источник, а `lookup` — новый алиас.

## Ключевые решения

- **Кэш, а не live-запросы:** детерминизм, скорость, работа офлайн; TTL
  только для URL (файлы сверяются по sha при `refresh_file`).
- **Глоссарий до retrieval:** дешёвый детерминированный слой снимает
  проблему «разных слов» до дорогого векторного поиска.
- **Переиспользование 2.4:** чанкинг, эмбеддеры и `pack_context` берутся
  как есть — обогащение это надстройка, а не второй RAG.
- **Stale как данные:** просроченный кэш не роняет ответ, а попадает
  в `stale_sources` — агент/человек решает, обновлять ли источник.
