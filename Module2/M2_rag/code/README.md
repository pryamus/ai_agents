# Лабораторная 2.4 — Контекстное окно и управление памятью (RAG)

**Цель:** настроить RAG для кодовой базы: индексация → поиск релевантных
файлов → упаковка контекста под бюджет токенов → передача агенту.

## Структура

```
lab_2_4_rag/
├── chunker.py     # чанкинг: AST для .py, заголовки для .md, окна с overlap
├── embedders.py   # TF-IDF (офлайн) и MiniLM (BERT) за единым интерфейсом
├── index.py       # плоский векторный индекс (numpy, косинус), save/load
├── context.py     # pack_context: отбор чанков под бюджет токенов
├── api.py         # FastAPI: GET /health, POST /index, /search, /ask
├── rag_demo.py    # CLI-демо того же пайплайна без сервера
└── tests/test_rag.py
```

## Шаги практики

1. **CLI-демо (быстрый старт, TF-IDF):**

   ```bash
   cd code/lab_2_4_rag
   python rag_demo.py --embedder tfidf --query "как ограничить число шагов агента"
   ```

   В выводе: сколько файлов и чанков проиндексировано, top-5 с оценкой
   релевантности и собранный промпт в рамках бюджета (`--budget 2000`).

2. **BERT-вариант (MiniLM, скачивается ~470 МБ один раз):**

   ```bash
   pip install sentence-transformers
   python rag_demo.py --embedder minilm --query "как агент обрабатывает ошибки инструментов"
   ```

   Сравните выдачу `tfidf` и `minilm` на запросе с синонимами
   («падения/ошибки/исключения») — TF-IDF ищет слова, MiniLM — смысл.

3. **Сервис:**

   ```bash
   uvicorn api:app --reload        # из каталога lab_2_4_rag
   curl -X POST localhost:8000/index -H "Content-Type: application/json" -d "{\"embedder\": \"tfidf\"}"
   curl -X POST localhost:8000/search -H "Content-Type: application/json" -d "{\"query\": \"роли агентов\", \"k\": 3}"
   curl -X POST localhost:8000/ask -H "Content-Type: application/json" -d "{\"question\": \"из чего состоит манифест агента\"}"
   ```

   `GET /health` показывает, построен ли индекс и каким эмбеддером.

4. **(Самостоятельно) Оценить качество:** возьмите 5 вопросов с известным
   ответом (файл:строка), посчитайте recall@3 = доля вопросов, где нужный
   файл попал в топ-3. Сравните для `tfidf` и `minilm`.

## Ключевые решения

- **Чанк ~300 токенов по границам функций** — семантически цельный и
  влезает в контекст в нескольких экземплярах.
- **Fallback TF-IDF → MiniLM** (`RAG_EMBEDDER=auto`) — практика работает
  без интернета; BERT подключается установкой одного пакета.
- **Бюджет в `pack_context`** — даже релевантный чанк не попадает в промпт,
  если он не помещается: контекстное окно ограничено и платно.
- **Несовместимые эмбеддеры при load() — ошибка:** векторы разных моделей
  живут в разных пространствах, косинус между ними бессмыслен.
