### @rate_limiter
```
@rate_limiter Нам нужно ограничить нагрузку на API с помощью slowapi и Redis. Выполни следующие шаги:

1. С помощью инструмента `run_command` проверь, установлены ли `slowapi` и `redis` (или `aioredis`). Если нет — установи их и обязательно зафиксируй новые версии в файле `requirements.txt`.
2. Настрой инициализацию `Limiter` из `slowapi` в главном файле приложения (например, `main.py` или `app.py`). Используй Redis в качестве бэкенда для хранения лимитов.
3. Предусмотри fallback-стратегию: если Redis временно недоступен или падает с ошибкой подключения, приложение НЕ должно падать — логируй ошибку и пропускай запросы без rate limit.
4. Добавь базовый лимит (например, 60 запросов в минуту) для всех эндпоинтов, и более строгий лимит (например, 5 запросов в минуту) на эндпоинты авторизации или создания тикетов, если они есть в проекте.
5. После внесения изменений запусти приложение или тесты через `run_command`, чтобы убедиться в отсутствии синтаксических ошибок.
```
