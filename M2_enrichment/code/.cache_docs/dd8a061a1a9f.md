# Деплой сервиса заказов

## Процедура выкатки

1. Прогнать проверки: `python -m pytest -q` и `ruff check .`.
2. Собрать артефакт и выложить на staging.
3. Дождаться зелёных smoke-тестов (эндпоинт `/health` отвечает `ok`).
4. Переключить трафик на новую версию (canary 10% → 100%).

## Откат (rollback)

Если после выкатки растут ошибки или latency p95 превышает порог:

1. Вернуть предыдущую версию одной командой `deploy rollback --to previous`.
2. Откат не трогает базу данных — миграции откатываются отдельно.
3. После отката зафиксировать причину в troubleshooting-разделе.

Откат считается успешной операцией, а не провалом: лучше быстрый rollback,
чем долгое разбирательство на проде.
