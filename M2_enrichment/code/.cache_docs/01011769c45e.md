# Справочник API сервиса

## Эндпоинты

- `GET /health` — состояние сервиса: `indexed`, число чанков, эмбеддер.
- `POST /index` — перестроить индекс по директории. Без вызова вернётся 409.
- `POST /search` — top-k релевантных чанков: `query`, `k`.
- `POST /ask` — retrieval + сборка промпта + вызов LLM.

## Пагинация и лимиты

Выдача поиска ограничена параметром `k` (1–20, по умолчанию 5).
Длинные ответы сервера обрезаются до `max_chars`/`max_output`, чтобы не
раздувать контекстное окно вызывающего агента.

## Коды ошибок

- `400` — неверные аргументы (нет директории, плохой JSON).
- `404` — по запросу ничего не найдено.
- `409` — индекс не построен.
- `503` — эмбеддер недоступен (нет сети для скачивания модели).
